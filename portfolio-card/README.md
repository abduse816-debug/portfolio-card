# Full-Stack Interactive Portfolio Card

A full-stack portfolio card web application featuring theme toggling, skill filtering, dynamic accent colors, social link integration, and a modal-driven contact form powered by Node.js and Nodemailer.

## Features

- **Theme Toggle:** Switch between Light and Dark modes seamlessly.
- **Accent Customization:** Dynamic color palette picker for UI customization.
- **Skill Filtering:** Categorized badge filtering system.
- **Interactive Contact Modal:** Sends real emails directly to Gmail using Express and Nodemailer.
- **Clipboard Utility:** One-click copy for email contact details.
- **Social Integration:** Circular action links connecting Telegram, Instagram, and Twitter (X).

## Tech Stack

- **Frontend:** HTML, CSS,  JavaScript , Font Awesome
- **Backend:** Node.js
- **Email Delivery:** Nodemailer (Gmail SMTP integration)
